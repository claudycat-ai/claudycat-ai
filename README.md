# Claudy Cat

日本語の小説を書く人のための道具を作っています。

## Sumire

書くのは自分。続きだけ AI に出してもらう、日本語 Web 小説のための執筆ツールです。
ローカル LLM（llama.cpp ほか）とクラウド AI を切り替えて使えます。Windows（x64）向けのデスクトップアプリです。

- [GitHub リポジトリ](https://github.com/claudycat-ai/Sumire)
- [紹介記事（note）](https://note.com/claudycat/n/n157df9665e43)
- [ダウンロード（BOOTH）](https://claudycat.booth.pm/items/9158205)

---

Sumire is a desktop app for writing Japanese web novels with inline AI suggestions you accept with Tab.
