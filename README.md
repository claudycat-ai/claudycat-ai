# Claudy Cat

日本語の小説を書く人のための道具を作っています。

## Sumire

書くのは自分。続きだけ AI に出してもらう、日本語 Web 小説のための執筆ツールです。
ローカル LLM（llama.cpp ほか）とクラウド AI を切り替えて使えます。Windows（x64）向けのデスクトップアプリです。
